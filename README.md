# C 语言练习项目 (C-Language-Practice)

这是我在学习 C 语言时写的练习项目，记录了我从基础语法到做出完整控制台小游戏的成长过程。

## 📁 包含的项目

### 1. 嵌套循环图案 (`xunhuan.cpp`)
利用双层嵌套循环，控制空格和星号的数量规律，打印金字塔等图形。

### 2. 控制台井字棋 (`井字棋.c`)
- **当前进度**：已完成 3x3 棋盘的绘制，通过 `while` 循环和 `scanf`，实现了玩家无限循环输入数字落子（目前只能下 'X'）。
- **核心技术**：`char` 字符变量、`if-else` 分支、`while(1)` 循环、格式化输入输出。
- **下一步计划**：加入双人回合交替（X 和 O 轮流），加入胜负判定逻辑。
