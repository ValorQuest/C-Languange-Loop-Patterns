# C 语言练习项目 (C-Language-Practice)

这是我在学习 C 语言时写的练习项目，记录了我从基础语法到做出完整控制台小游戏的成长过程。

## 📁 包含的项目

### 1. 嵌套循环图案 (`xunhuan.cpp`)
利用双层嵌套循环，控制空格和星号的数量规律，打印金字塔等图形。

### 2. 控制台井字棋 (`井字棋.c`)
- **当前进度**：已完成 3x3 棋盘绘制，并通过 `while` 和 `goto` 实现无限循环。成功加入 `turn` 变量实现【双人回合交替】，X 和 O 能完美轮流落子。
- **核心技术**：`char` 字符变量、`if-else` 分支、`else if` 互斥逻辑、状态变量（`turn`）的应用。
- **下一步计划**：学习数组（Array），重构 9 个变量的冗余代码，并加入防耍赖（防覆盖）与胜负判定逻辑。
